# FlowForge

## PrivateVoice

[`PrivateVoice/`](PrivateVoice/) is a private, offline Android app that reads incoming text messages aloud with on-device neural voices (Kokoro-82M). You can give individual senders their own voices.

See [PrivateVoice/README.md](PrivateVoice/README.md) for build, install and usage instructions, [PRIVACY.md](PrivateVoice/PRIVACY.md) for the privacy design, and [TEST_RESULTS.md](PrivateVoice/TEST_RESULTS.md) for what has been verified.
